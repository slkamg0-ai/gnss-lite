# SW Maps + 폰 설정 순서 (간이측량기 RTK 연결)

UM982 보드의 RTK 위치를 폰의 간이측량기 앱에서 쓰는 방법이다. **SW Maps가 USB로 보드를 읽고 NTRIP 보정을 넣은 뒤, 그 위치를 "모의 위치"로 안드로이드에 내보내면 앱이 그 위치를 받는다.**
2026-10-08 야외에서 RTK FIX와 앱 측량이 확인된 순서다(삼성 안드로이드 폰 기준, 화면 이름은 폰마다 조금 다를 수 있다).

```
안테나(J1) ─ UM982 보드 ─USB-C─ 폰 ┬ SW Maps: NTRIP 보정 + RTK 위치 → 모의 위치
                                    └ 간이측량기 앱: 폰 GPS 소스로 그 위치를 받음
```

## 준비물
- UM982 보드, 안테나(주안테나 `J1`에 연결), USB-C 케이블(안 되면 USB-A OTG 어댑터)
- 국토지리정보원 VRS(NTRIP) 계정 — 아이디, 비밀번호, 마운트포인트. **비밀번호는 문서·채팅에 적지 않는다.**
- 폰 데이터 통신, SW Maps 앱, 간이측량기 앱(`https://gnss-lite-field.slkamg0.workers.dev`)

## 1. 폰 설정 (처음 한 번)
1. 설정 ▸ 휴대전화 정보 ▸ 소프트웨어 정보에서 **빌드번호를 7번** 눌러 개발자 옵션을 켠다.
2. 개발자 옵션 ▸ **가상 위치 앱 선택** ▸ **SW Maps**.
3. (결과가 안 나올 때만) 설정 ▸ 위치 ▸ 위치 서비스에서 *Google 위치 정확도*와 *Wi-Fi/블루투스 검색*을 끈다.
4. SW Maps를 배터리 최적화 제외(제한 없음)로 둔다.

## 2. SW Maps 설정
1. 보드를 폰에 USB로 연결하고 USB 접근을 허용한다.
2. SW Maps에서 **USB 연결**로 보드를 연결한다(속도 115200). 위성 수가 보이면 연결된 것이다.
3. **NTRIP 설정**: 서버 `vrs.ngii.go.kr`, 포트 `2101`, 마운트포인트는 소스테이블에서 VRS 방식(RTCM 3.x) 항목, 본인 계정. 연결되면 Age가 1초 안팎으로 갱신된다.
4. **설정 ▸ Location ▸ `Enable Mock Location Output`을 체크**한다. ← **가장 중요.** 이것이 꺼져 있으면 앱은 일반 폰 위치(3~5 m)를 받는다.
5. SW Maps는 **계속 켜 둔다.** 화면 위쪽 알림에 "Mock location 사용 중"이 보여야 한다.

## 3. 간이측량기 앱 설정
1. 앱을 열고 설정 ▸ 위치 소스 ▸ **폰 GPS**.
2. 설정 ▸ 측량 조건: 좌표계(현장 기준), **안테나 높이**(폴 끝에서 안테나 바닥면 + 위상중심 보정), 평균 시간, 허용 오차.
3. 폴과 폰을 고정하기 전에는 **기울기 보정을 끄고** 폴을 수직으로 세운다.

## 4. 연결 확인
| 확인 | 정상 |
|---|---|
| SW Maps 상태 | **RTK FIX**, ΔH/ΔV가 수 cm (예 1.4 / 3.4 cm), Age 약 1초 |
| 폰 알림 | "Mock location 사용 중 — SW Maps" |
| 앱 상단 | **FIXED**, 정밀도 H/V cm가 SW Maps와 비슷 (예 1.8 / 3.7) |
| 측량 | 점 측량(평균)이 성공 |

## 5. 문제 해결
| 증상 | 원인 | 해결 |
|---|---|---|
| 앱 정밀도가 **3~5 m**, SINGLE | 앱이 모의 위치가 아닌 일반 위치를 받음 | 1-2의 모의 위치 앱 선택, 2-4의 Mock Location Output 체크 확인, 1-3의 위치 서비스 설정 |
| SW Maps가 Float에서 안 올라감 | 하늘 가림, 다중경로 | 사방이 트인 곳에서 안테나를 **알루미늄 원판 위**에 고정하고 3~5분 대기. 창틀·건물 옆은 어렵다 |
| 앱에 "수신 끊김" | SW Maps가 절전으로 멈춤 | 배터리 제한 없음, 화면 켜 둠 |
| 측량이 막힘 | 노란 경고 줄 확인 | `IMU…` → 기울기 보정 끔. `고도 정보 없음` → SW Maps 고도 전달 확인 |
| "GL 확정"을 눌렀는데 확인 창이 뜸 | 목표 측점에서 멀리 있음 | 시험 중이면 "확인"을 누르거나 **측량 탭의 점 측량**을 쓴다 |
| 원인을 모르겠음 | — | 설정 ▸ **수신 진단 ▸ 진단 복사**(좌표 미포함) 내용을 보낸다 |

## 알아둘 점
- 이 연결은 **안드로이드 모의 위치를 이용한 우회 경로**라서 폰 제조사·안드로이드 버전에 따라 동작이 다를 수 있다. 상용 제품은 전용 앱이 보드를 직접 읽는 구조로 옮길 계획이다.
- 앱의 Fix 표시는 SW Maps가 전달하는 **정확도 값**(5 cm 이하 = FIXED)으로 추정한다. 확실한 RTK 상태는 SW Maps 화면에서 본다.
- 높이(지반고)는 지오이드 차이가 있을 수 있어 **기지점에서 현장 보정(높이)** 을 한다.
