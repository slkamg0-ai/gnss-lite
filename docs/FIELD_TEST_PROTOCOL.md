# 핸드헬드 RTK 현장 시험 절차서 (10/30 목표)

목적: UM982 + BT-T009 + 폰 앱으로 만든 간이측량기가 **실제 작업에 쓸 만한 정확도·안정성**인지 숫자로 확인하고, 건설신기술·상용화 증빙 자료를 쌓는다.
기록 양식: `docs/field-test-sheet.csv` (엑셀로 열어 쓴다). 앱 기록은 설정 ▸ 수신 기록 · 데이터 수집에서 내려받는다.

> 아래 합격 기준은 **제안값**이다. 첫 시험 결과를 보고 조정한다. 실제 하드웨어로는 아직 한 번도 시험하지 않았다.

## 0. 시험 전 준비 (한 번만)
| # | 항목 | 확인 |
|---|---|---|
| 0-1 | 앱을 폰에 설치(`docs/HOSTING.md`), 위치 권한 허용, 비행기 모드에서 실행 확인 | ☐ |
| 0-2 | 폰 홀더는 **기계식 클램프**, 자석 케이스·자석 거치대 제거 | ☐ |
| 0-3 | 폴 길이·원판 두께·어댑터 30 mm를 줄자/캘리퍼스로 **실측해 기록** (안테나 높이 h = 폴 끝에서 안테나 바닥면) | ☐ |
| 0-4 | NTRIP 계정(국토지리정보원 VRS) 확인, 폰 데이터 요금제 확인 | ☐ |
| 0-5 | 설정 ▸ 좌표계를 **기지점 좌표의 좌표계**와 같게 맞춤 (예: EPSG:5186) | ☐ |
| 0-6 | 설정 ▸ 데이터 ▸ **백업** 한 번 내려받기 | ☐ |
| 0-7 | 기지점(좌표를 아는 점) **3개 이상** 확보: 국가·지적 기준점, 도근점, 토탈스테이션으로 따낸 점 | ☐ |

기지점은 **서로 다른 장소(가능하면 개활지·수목 근처·건물 옆)** 로 고른다. 도면에서 읽은 맨홀 좌표는 정확도를 보장할 수 없으니 정답으로 쓸 때 주의한다.

## 1. 책상 시험 (보드 도착 직후, 실내 창가 또는 옥외)
1. PC에 UPrecise 설치, 보드를 USB로 연결 → COM 포트 인식, 위성 수신 확인.
2. NMEA 출력(GGA, GST, GSV, GSA)과 저장 명령을 **제조사 매뉴얼로 확인해** 설정한다. (README의 명령은 미검증)
3. 보드를 폰에 USB-C로 연결 → 인식이 안 되면 **USB-A OTG 어댑터 경로**를 시도.
4. SW Maps(또는 앱의 USB 시리얼)로 NTRIP 연결, **FIXED 도달 시간** 기록.
5. 앱 설정 ▸ 위치 소스 ▸ 폰 GPS로 위치·Fix 상태가 보이는지 확인.
- 합격: 폰에서 위치가 나오고 FIXED에 도달한다. (안 되면 5번 문제 대응 표로)

## 2. 현장 시험 항목
각 항목에서 **날짜·장소·환경·Fix 상태·위성 수·HDOP**를 반드시 같이 기록한다.

### T1. FIXED 도달 시간
- 방법: 전원을 켠 직후부터 FIXED가 될 때까지 시간을 잰다. 개활지에서 5회(켜고 끄기 반복).
  앱 설정 ▸ 수신 기록 카드의 **통계 줄 "첫 FIXED ○초"** 를 읽는다(위치 수신을 시작한 순간부터 센다). 매 회 **통계 초기화**를 누른다.
- 기록: 도달 시간(초).
- 합격(제안): 평균 ≤ 60 초 (콜드 스타트는 별도 기록)

### T2. 기지점 정확도 (가장 중요)
- 방법: 기지점 3곳 이상에서 **폴을 수직으로 세우고**(버블 확인) 평균 시간 30 초로 측정. 지점마다 10회.
  앱의 **정답 측정**(설정 ▸ 수신 기록 ▸ 정답점 선택)을 쓰면 오차가 정답 라벨로 자동 기록된다.
- 계산: dN, dE, d2D = √(dN²+dE²), dZ. 지점별 평균·RMS·최대.
- 합격(제안, 개활지·FIXED): **수평 RMS ≤ 2 cm, 수직 RMS ≤ 4 cm**
- 수직은 지오이드 차이와 안테나 위상중심 때문에 일정한 편차가 날 수 있다 → 기지점 1곳으로 **현장 보정(높이)** 후 다른 기지점에서 다시 확인한다.

### T3. 반복성
- 방법: 한 점에서 폴을 들었다 다시 세워 측정하기를 10회(매번 다시 조준).
- 합격(제안): 수평 표준편차 ≤ 1.5 cm

### T4. 기울기 보정 효과
- 준비: 설정 ▸ 폴 기울기 보정 ▸ **수평 캘리브레이션**(버블 수평 3초) → **방위 캘리브레이션**(관 진행방향으로 5~10° 기울여 누르기).
- 방법: 폴 끝을 기지점에 고정하고 **북·동·남·서로 각각 3°, 5°, 10°** 기울여 측정(보정 ON/OFF 각각). 기울기 각도는 폰 센서 값과 각도기/수평계로 같이 기록.
- 이론값: 1.8 m 폴이 3° 기울면 수평 약 94 mm, 5°면 약 157 mm.
- 확인: **북쪽으로 기울였을 때 앱의 기울기 방위가 북으로 나오는지**(어긋나면 좌표 방향 설정을 바꿔 다시 캘리브레이션).
- 합격(제안): 보정 ON에서 5° 잔차 ≤ 2 cm

### T5. 환경별 Fix율 (기록 켜 두기)
- 방법: 설정 ▸ 수신 기록 ▸ **● 연속 기록 시작**을 누르고 각 환경에서 5분 정지 측정 후 종료.
  환경: ① 개활지 ② 수목 아래 ③ 건물 옆(한쪽 가림) ④ 도심(양쪽 건물)
- 기록: 환경별 FIXED/FLOAT/기타 비율(통계 줄 **FIXED ○% · FLOAT ○%**), 위성 수, 첫 FIXED까지 시간. 환경을 옮길 때마다 **통계 초기화**.
- 합격(제안): 개활지 FIXED ≥ 90%. 나머지는 **기준값 수집용**(다중경로 학습 자료).

### T6. NTRIP 연결 안정성
- 방법: 개활지에서 30분 정지 기록.
- 기록: 통계 줄의 **FIXED 이탈 ○회(재획득 평균 ○초)**, **수신 끊김 ○회**(3초 이상 무수신), FIXED 비율.
- 합격(제안): 끊김 후 재연결 ≤ 30 초, FIXED 유지 ≥ 90%

### T7. 스테이크아웃 실작업 (관로 5 m 측점)
- 방법: 앱의 관로 구간으로 측점을 만들어 **실제 말뚝을 박고**, 별도 방법(줄자·토탈스테이션)으로 위치를 확인.
- 기록: 측점별 확인 오차, 작업 시간, 사용 중 불편한 점.
- 합격(제안): 측점 위치 오차 ≤ 3 cm, 5 m 측점 한 개당 작업 시간 기록

### T8. 연속 사용 (배터리·발열)
- 방법: 2시간 연속 사용. 폰 배터리 감소율, 보드 발열, 연결 끊김 기록.
- 합격(제안): 2시간 동안 끊김 없음, 폰은 충전기 병용 가능

### T9. 음성 명령 (선택)
- 방법: 현장 소음(바람·장비) 속에서 명령 20개를 말해 보고 성공/실패 기록.
  앱 기록(명령 로그)의 인식 결과와 의도 해석이 남는다.
- 기록: 성공률, 오인식 사례

## 3. 오차 계산 (엑셀)
측정N, 측정E, 측정Z와 기지점 좌표를 같은 시트에 놓고:
- `dN = 측정N − 기지점N`, `dE = 측정E − 기지점E`, `dZ = 측정Z − 기지점Z`
- `d2D = SQRT(dN^2 + dE^2)`
- RMS = `SQRT(AVERAGE(d2D^2))`, 95% = 정렬한 d2D의 95번째 백분위, 최대 = `MAX(d2D)`
- 반복성: 같은 점 10회의 N·E 표준편차 `STDEV`

## 4. 기록해 둘 것 (증빙 자료)
- 장비 사진: 폴 전체, 안테나·어댑터·원판, 보드 연결 상태
- 안테나 높이 실측 값과 측정 방법
- 앱 버전(설정 화면 하단 `GNSS-Lite v…`)과 설정 스냅샷(설정 화면 캡처)
- 시험별 날씨(맑음·흐림·비), 시간대
- 앱 기록 파일(수신 기록, 측정 로그, 명령 로그): 날짜별로 이름을 붙여 보관

## 5. 문제 대응 표
| 증상 | 확인 순서 |
|---|---|
| 폰이 보드를 인식 못 함 | 데이터 케이블인지 → USB-A OTG 경로 → 다른 폰 포트 → PC에서는 되는지 |
| 위성은 보이는데 FIXED가 안 됨 | NTRIP 연결·계정 → 마운트포인트 → 안테나 케이블/단자(ANT1) → 하늘 가림 |
| 위치가 수 m 틀림 | 좌표계(EPSG) 설정 → 높이 기준(지오이드) → 기지점 좌표계 |
| 수직만 일정하게 어긋남 | 안테나 높이 입력 → 위상중심 오프셋 → 기지점 높이 보정으로 흡수 |
| 기울이면 위치가 크게 흔들림 | 수평 캘리브레이션 재실행 → 폰 홀더 고정 → 자기 간섭(자석) 제거 |
| 방위 캘리브레이션 후에도 방향 반대 | 북쪽 기울임 시험으로 방위 확인 → IMU 세계 프레임 설정 변경 |
| 앱이 갱신 안 됨 | 앱 완전 종료 후 재실행 → 주소창 새로고침 |

## 6. 안전
- 도로·장비 근처 작업 시 안전 조끼와 주변 확인. 폰 화면을 보며 걷지 않는다.
- 긴 폴은 **고압선·가공선** 가까이에서 세우지 않는다.
- 시험 때 말뚝을 박는 작업은 지하 매설물 확인 후 진행한다.
