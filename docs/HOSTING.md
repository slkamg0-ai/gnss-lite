# 앱을 폰에서 쓰려면 — HTTPS 호스팅 안내

폰에서 **위치(GPS)·USB 시리얼·블루투스·서비스워커(오프라인)** 를 쓰려면 앱이 `https://` 주소(또는 `localhost`)에서 열려야 한다.
PC의 `http://192.168.x.x` 같은 주소는 폰에서 위 기능이 막힌다. 그래서 앱 파일을 무료 호스팅에 올려 https 주소를 만든다.

## 1. 배포용 폴더 만들기 (이미 검증됨)
```bash
cd gnss-lite
npm run build:site      # → dist/ 폴더 생성 (앱 실행에 필요한 파일 15개)
```
`dist/` 안에는 앱 파일, 서비스워커, 아이콘, `_headers`, `.nojekyll`, `VERSION.txt` 만 들어 있다(테스트·펌웨어·도면 제외).
검증: 별도 서버로 열었을 때 서비스워커 활성, 필수 파일 12개 전부 캐시, 콘솔 오류 없음 (2026-10-04).

## 2. 올리는 방법 (택 1, 모두 무료 플랜 가능)
> 각 서비스의 화면 이름·버튼은 바뀔 수 있다. 가입·로그인·약관 동의는 **본인이 직접** 한다.

### A. Cloudflare Pages 또는 Netlify — 폴더 끌어놓기 (가장 쉬움, 권장)
1. 서비스에 가입한다(이메일).
2. 새 사이트를 만들 때 **직접 업로드(Direct upload / Drop)** 를 선택한다.
3. `gnss-lite\dist` **폴더째** 끌어다 놓는다.
4. 발급된 `https://…` 주소를 받아 적어 둔다.
- 코드가 공개 저장소에 올라가지 않는다. 주소를 아는 사람은 누구나 열 수 있다.

### B. GitHub Pages
1. GitHub에 저장소를 만든다. **무료 플랜은 공개(public) 저장소여야 Pages를 쓸 수 있다.**
2. `dist` **안의 파일들**을 저장소 루트에 올린다(`.nojekyll` 포함).
3. 저장소 ▸ Settings ▸ Pages 에서 배포 브랜치를 지정한다.
4. 주소는 `https://계정.github.io/저장소이름/` 형태다. 앱 경로가 모두 상대경로라 이 하위 주소에서도 동작한다.
- 앱 코드가 공개된다. 앱에는 개인 정보·키가 들어 있지 않다(키는 폰 브라우저에만 저장).

### C. 호스팅 없이 책상 시험 (USB 연결)
PC의 개발 서버를 폰의 `localhost`로 연결한다. 폰의 USB 디버깅이 켜져 있어야 한다.
```bash
adb reverse tcp:8765 tcp:8765      # PC에서 (Android platform-tools 필요)
python -m http.server 8765 --directory gnss-lite    # 같은 PC에서 서버 실행
# 폰 Chrome 에서 http://localhost:8765 열기
```
`localhost`는 보안 컨텍스트라 위치·서비스워커가 된다. USB 시리얼(Web Serial) 동작은 안드로이드 Chrome 버전에 따라 다를 수 있어 **실기기 미검증**이다.

## 3. 폰에 설치하기
1. 폰 Chrome으로 위 https 주소를 **인터넷이 되는 곳에서** 연다(처음 한 번은 온라인).
2. ⋮ ▸ **홈 화면에 추가** (또는 앱 설치).
3. 위치 권한을 허용한다.
4. **비행기 모드로 켜 보아 오프라인 실행을 확인**한다. 현장 음영지역 대비용이다.

## 4. 앱을 고쳤을 때 업데이트
```bash
npm run build:site       # dist 다시 생성
```
같은 서비스에 `dist`를 다시 올린다. 앱은 접속할 때마다 최신 파일을 먼저 받아 오고(네트워크 우선), 실패하면 저장된 파일을 쓴다.
새 버전이 안 보이면 앱을 완전히 닫았다 다시 열거나, Chrome 주소창에서 새로고침한다.

## 5. 주의
- 주소(URL)는 비밀번호가 아니다. 아는 사람은 앱을 열 수 있지만, **측량 데이터는 폰 브라우저 안에만 저장**되어 서버로 가지 않는다.
- AI(Claude)·음성(ElevenLabs) 키를 넣었다면 그 폰에만 저장된다. 백업 파일에는 포함되지 않는다.
- 데이터는 **설정 ▸ 데이터 ▸ 백업**으로 주기적으로 내려받아 둔다. 브라우저 데이터를 지우면 사라진다.
